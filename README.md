# CC Research 2026 — Medicine Dispensing Device

Research and engineering website documenting the development
of a personalized in-home medication dispensing prototype.

## Technology

- Astro
- Tailwind CSS
- Google model-viewer
- GitHub Pages
- GitHub Actions

## Local Development

npm install
npm run dev

## Production Build

npm run build
npm run preview

## Repository Structure

src/
  components/
  layouts/
  pages/
  styles/

public/
  images/
  models/

## Deployment

Pushes to main are deployed to GitHub Pages through
.github/workflows/deploy.yml
